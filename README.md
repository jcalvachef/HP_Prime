## PaviFlex

Aplicación Android para la inspección visual de pavimentos flexibles (metodología INVIAS):
registro fotográfico de daños con escala por regla de 1 m, coordenadas EPSG:9377, plano sobre
mapa base sin clave de API e informe en PDF y Word sobre el rótulo. Ver [`paviflex/README.md`](paviflex/README.md).
